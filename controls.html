🎮 Keyboard controls

EmulatorJS controls can vary by configuration. Check the emulator's Controls or Settings menu for the active key bindings.

  • Arrow keys — directional movement
  • Z / X — common default A/B buttons
  • Enter — commonly Start
  • Backspace — commonly Select

These are common defaults, not guaranteed bindings. You can remap controls in EmulatorJS settings.

💾 Save your progress

  1. In-game save: Use the game's own save option. This is generally the best way to preserve normal game progress.
  2. Save state: Use EmulatorJS's save-state feature to capture your current emulator session. Download the file if the interface offers that option.
  3. Back up your files: Keep downloaded saves somewhere safe and make occasional backups.
  4. Restore a save state: Use EmulatorJS's load-state feature to select a previously exported state file.

⚠️ Important save advice

Browser storage can be cleared, and saves may not transfer between different browsers or hosting origins. Private browsing can also affect persistence.

Export important saves when possible. Do not assume that browser cache, an in-game save, and a save state are interchangeable.
